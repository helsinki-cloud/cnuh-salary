# 전남대학교병원 일반직 연봉 계산기

직급·호봉·근속연수·가족사항을 넣으면 월별 지급명세, 예상 총연봉, 실수령액(참고)을 계산합니다.
「장기 시뮬레이션」 탭에서는 호봉 승급·승진·기본급 인상률을 반영해 최대 40년치 연봉을 보여줍니다.

👉 사용하기: https://helsinki-cloud.github.io/cnuh-salary/

## 계산 기준
- 2025년 단체협약 기준 봉급표 및 수당
- **사학연금: 월 고정 지급총액(기본급+고정수당) × 9%** — 상여·명절휴가비가 나오는 달에도 늘어나지 않음
- **소득세: 근로소득 간이세액표(소득세법 시행령 별표 2, 2026.3.1. 시행)** 조회 — 비과세 식대(월 20만원)를 뺀 월급여와 공제대상 가족 수 기준, 8~20세 자녀 공제 반영
- 주민세(지방소득세) = 소득세 × 10% (10원 미만 절사)
- 건강보험 3.595%, 장기요양 건보료×13.14% → 실수령액은 참고값

## 규정 업데이트 방법
`index.html` 안의 `설정값` 블록(`PAY_TABLE`, `GRADE_ALLOW`, `FAMILY_ALLOW`, `WELFARE`, `RATES`)만 고치면 됩니다.
간이세액표가 개정되면 `tax-table-2026.js`를 새 표로 바꾸면 됩니다.
값이 `null`인 항목은 아직 확인되지 않은 값이며, 계산에서 0원으로 처리되고 화면에 경고가 표시됩니다.

## 주의
개인이 만든 참고용 도구이며, 전남대학교병원의 공식 서비스가 아닙니다. 병원의 공식 급여 산정과 다를 수 있습니다.
